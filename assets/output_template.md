# 输出模板

渲染规则：
- 严格用下面的骨架，不要增删区块，不要换成 Markdown 表格。
- `{{...}}` 为占位符，取值一律来自脚本 JSON 输出，不要手算。
- 单位统一：热量 `kcal`、价格 `¥`、蛋白质 `g`。
- 顶踩用 `👍 n  👎 n  💬 n条评论`；无评论写 `💬 暂无评论`。
- **命中优惠券写「券后 ¥xx」，未命中写「实付 ¥xx」**，不要统一写"券后"。
- 价格若来自估算（`price_is_estimate: true` 且未复核），在价格后加 `≈`，如 `券后 ≈¥23.5`。
- 免费冰水在方案明细里标 `冰水（免费）`。

---

## 模板 A：系统推荐区

```
🏆 系统推荐 · {{约束描述}}          ← 例：500大卡以内 / 预算¥30 / 蛋白质≥25g

方案{{rank}}：{{summary}}
  热量 {{calories}}kcal | 蛋白质 {{protein}}g | {{价格前缀}} ¥{{final_price}}
  {{price_note}}                  ← 命中券写「用了「{{coupon_name}}」」；未命中券写「无可用券」；估算未复核时补「估算价」
  👍 {{up}}  👎 {{down}}  💬 {{comment_count}}条评论
  "{{top_comment_1}}"             ← 无评论则整行省略

（重复方案2、方案3……）

{{relaxed_notice}}                ← 仅当 relaxed=true 时输出，例：
                                   ⚠️ 严格约束下无可行组合，已放宽热量上限至 550kcal

━━━━━━━━━━━━━━━━━━━━━━

🎲 今日推荐 · 来自社区
{{explore_tag}}                   ← explore=true 时前缀「✨ 新品尝鲜 · 」

🔥 {{title}}  by {{author_or_匿名}}
   {{summary}}
   热量 {{calories}}kcal | {{价格前缀}} ¥{{final_price}}
   👍 {{up}}  👎 {{down}}  💬 {{comment_count}}条评论
   "{{top_comment_1}}"

（picked 为空时,替换为:）
   📭 {{notice}}

━━━━━━━━━━━━━━━━━━━━━━

回复「换一个」换一条社区推荐。
回复「顶」「踩」「评论 内容」互动。
回复「发布方案1」分享到搭配区。
回复「看看搭配区」浏览全部社区组合。
```

## 模板 B：用户搭配区

```
📚 用户搭配区 · 按{{排序名}}排序     ← 热度 / 最新 / 价格 / 热量

🔥 {{title}}  by {{author_or_匿名}}
   {{summary}}
   热量 {{calories}}kcal | {{价格前缀}} ¥{{final_price}}
   👍 {{up}}  👎 {{down}}  💬 {{comment_count}}条评论
   "{{top_comment_1}}"

（重复下一项，最多 10 条；无数据时输出：）
   📭 搭配区还空着，回复「创建」发布第一个组合。

回复「顶2」「踩3」「评论2 内容」互动。
回复「创建」发布你自己的组合。
```

排序名映射：`hot`→热度、`new`→最新、`price`→价格、`calories`→热量。
序号从 1 开始，对应列表顺序，供用户用「顶2」这类指令引用。

## 模板 C：交互回执（投票 / 评论 / 发布后）

```
✅ {{动作}} 成功
   {{title}} · {{summary}}
   👍 {{up}}  👎 {{down}}  💬 {{comment_count}}条评论
```

动作取值：
- 投票 → `已顶` / `已踩` / `已改票`
- 评论 → `评论已发布`
- 发布 → `已发布到搭配区`（`action: updated` 时写 `该组合已存在，已更新并复用原评论`）

## 模板 D：无结果 / 报错

```
⚠️ {{error}}
   当前约束：热量 ≤{{calories}}kcal ｜ 预算 ≤¥{{price}} ｜ 蛋白质 ≥{{protein}}g
   可以试试：放宽预算到 ¥{{suggested_price}}，或换一家门店。
```

`{{error}}` 取 `data.error` 或 `data.notice`，原文转述。
